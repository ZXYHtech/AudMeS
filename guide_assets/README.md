# SA-440F5 测试引导图资源

本目录用于放置 SA-440F5 一键测试向导中的步骤图片。

软件会按下面的文件名自动加载；如果对应图片不存在，则显示内置的仪器风格占位图，不影响测试流程。

- sa440f5_step_01.png — 设备与安全检查
- sa440f5_step_02.png — E4x4 Pre Loopback 基准
- sa440f5_step_03.png — 1 kHz 增益测试接线
- sa440f5_step_04.png — 20 Hz–40 kHz Sweep
- sa440f5_step_05.png — 1 kHz THD / FFT
- sa440f5_step_06.png — 低噪声测量
- sa440f5_step_07.png — 结果复核与报告

建议图片尺寸：1240×720 或同等 16:9 比例。程序显示时会缩放为约 620×360。

本次代码改造不生成新图片。后续可把已确认的测试指导图直接按上述文件名替换进来，无需修改 C++ 代码。
